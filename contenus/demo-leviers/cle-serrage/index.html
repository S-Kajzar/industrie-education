Serrer un écrou de roue

Durée conseillée : 20 min · 3 questions

Données

  • Couple de serrage préconisé pour l’écrou : 110 N·m.
  • Longueur utile de la clé, de l’axe de l’écrou à la main : 0,40 m.
Q1Quelle force la main doit-elle exercer pour atteindre le couple préconisé ?1 point
Voir la correction

F = M / d = 110 / 0,40 = 275 N

Q2Avec une rallonge, la longueur utile passe à 0,60 m. Quelle force faut-il maintenant ?1 point
Voir la correction

F = 110 / 0,60 ≈ 183 N

Q3Pourquoi la rallonge facilite-t-elle le serrage ? Réponds en une phrase.1 point
Voir la correction

Elle augmente le bras de levier : pour le même moment, la force nécessaire diminue.
